# TVL Intelligent Textbook

> **Archived page.** Landing page for a retired MkDocs build of the TVL site, not published on tvl-lang.org; the site
> book lives in [`website/client/src/book/chapters/`](../../../website/client/src/book/chapters/). Kept as source notes.

![Traigent Robot Trainer](../images/robot-trainer.svg){ width="720" }

*Take AI agents from experimental toward production with governed configuration, scoped checks, and evidence-based promotion.*

Welcome to the Traigent Labs companion for the Tuned Variables Language (TVL). This site packages the book,
hands-on labs, walkthroughs, and playground resources that teach engineers how to:

- Capture configuration as **TVL specs** instead of brittle YAML scattered across services.
- Use **TVO** (the TVL Optimizer in the Traigent platform) to search the declared configuration space within
  multi-objective budgets.
- Validate evaluation datasets with **DVL** (a data-validation layer outside TVL) before promoting any configuration.
- Keep promotion trails auditable with deterministic exports and CI gates.

The material blends narrative chapters, runnable examples from the `Traigent` repository, and an interactive
Streamlit playground. Start with the [TVL Intelligent Textbook](../book/index.md) chapter map or jump directly
to a [hands-on lab](../book/labs.md) to run an optimization.
